HTML Vault

Pilih file .htmlvault dan masukkan password untuk mendekripsi serta melihat HTML di browser ini.

File dan password diproses di browser. Kode contoh ini tidak mengunggahnya ke server. Jangan gunakan halaman ini jika Anda menambahkan skrip pihak ketiga yang tidak tepercaya.

Untuk mengedit, gunakan aplikasi Windows HTML Vault untuk mendekripsi menjadi file .html. Browser tidak menyimpan file hasil dekripsi ke disk dari halaman ini.
